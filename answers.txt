Q : Is JAVA a Pass by Value or a Pass by Reference programming language?
A : Java is pass by value

Q : After the call of swap(jungleDVD, cinderellaDVD) why does the title of these two 
objects still remain?
A : when swap is called, o1 and o2 are copies of the two DVDs, so swap just does an internal value swap that does not affect the original

Q : After the call of changeTitle(jungleDVD, cinderellaDVD.getTitle()) why is the title of the JungleDVD changed?
A : changeTitle calls a mutator, which directly mutates the original value
